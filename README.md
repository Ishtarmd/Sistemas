# Estudio SCPI (app)

App para preparar el examen de Sistemas de Control en la Producción Industrial (viernes 16 de octubre).

Funciona en el móvil y la tablet, y **sin conexión** una vez abierta.

## Qué incluye

- **Plan** del 1 al 15 de octubre.
- **Tests por tema**, con 511 preguntas:
  - Guarda tu mejor nota.
  - Guarda los fallos, que repasas con **«Repasar mis fallos»**. Cada pregunta que aciertas sale de la lista.
- **Chuleta de errores**: tablas cortas con lo que más se falla en cada tema.
- **Parcial I**.
- **Medidores y válvulas en 2D y 3D**, con aplicaciones y modo guiado.

## Publicarla con GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo `estudio-scpi`. Puede ser público o privado. Si es privado, GitHub Pages solo funciona con un plan de pago.
2. Sube **el contenido de esta carpeta**, no la carpeta en sí: `index.html`, `sw.js`, `manifest.webmanifest`, `icons/`, `.nojekyll` y el resto de páginas. Desde la web vale con **Add file → Upload files** y arrastrar todo.
3. Ve a **Settings → Pages** y configura:
   - **Source:** Deploy from a branch.
   - **Branch:** `main`.
   - **Carpeta:** `/ (root)`.
   - Pulsa **Save**.
4. En uno o dos minutos la app estará en `https://TU-USUARIO.github.io/estudio-scpi/`.

## Instalarla en el móvil o la tablet

- **iPhone o iPad (Safari):** abre el enlace, pulsa **Compartir** y luego **Añadir a pantalla de inicio**.
- **Android (Chrome):** abre el enlace, pulsa el menú **⋮** y luego **Instalar aplicación** (o **Añadir a pantalla de inicio**).

Ábrela una vez con internet y recorre las secciones que vayas a usar. A partir de ahí funciona sin conexión.

Las notas y los fallos se guardan en cada dispositivo por separado: no se pasan del móvil a la tablet.
